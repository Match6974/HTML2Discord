# 記事解析仕様
既知の書式（■、【】・〖〗、・、└、＜調整意図＞等）は候補であり、実HTML調査後に確定する。
1. HTML構造と既知の書式で通常解析。
2. 全半角・括弧・箇条書き等の表記揺れを解析用コピーで吸収。原文は変更しない。
3. 未知の項目は原文と位置を保持し警告。αβγ以外、HP、特殊アクション、格闘等も対象。
- 調整意図がない場合は欄を非表示。数値補完は明示的根拠のみ。
- 未解析部分や欠落を検出し、解析不完全時は正常な画像として自動投稿しない。警告・原文・公式URLを通知する（通知実装は後工程）。
- 元HTML、構造化JSON、未解析原文、ログを保存する。
- 意味判定不能と構造解析失敗を区別する。
