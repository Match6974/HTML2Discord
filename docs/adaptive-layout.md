# STEP6-⑦ 可変レイアウト

## 確定方針
- 1920×1080 PNG。
- 同一ページ内で1〜3列を混在可能とする（B案）。
- 内容に応じて列数を自動選択する。
- 公式記事の掲載順を維持する。
- キャラクターは可能な限り同一ページにまとめ、調整項目の途中では分割しない。
- 共通調整の対象一覧にも複数列を適用する。
- 記事全体でページ番号を通す。

## 暫定制約
- 最小縮小率70%、フッター余白24px以上を維持する。
- 文字切れ、重なり、調整項目の欠落・重複を禁止する。

## 実装順序
- [x] ① レイアウト仕様確定
- [x] ② 2列配置
- [x] ③ 3列配置
- [x] ④ 複数キャラクター配置
- [ ] ⑤ 列数自動選択・混在
- [ ] ⑥ 共通調整の最適化
- [ ] ⑦ 改ページ・はみ出し検証
- [ ] ⑧ 回帰テスト・画像枚数比較

既存の画像生成経路を維持し、試作を独立して検証してから統合する。
