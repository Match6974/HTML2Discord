# STEP6-⑦ 可変レイアウト

## 確定方針
- 1920×1080 PNG。
- 同一ページ内で1〜3列を混在可能とする（B案）。
- 内容に応じて列数を自動選択する。
- 公式記事の掲載順を維持する。
- キャラクターは可能な限り同一ページにまとめ、調整項目の途中では分割しない。
- 共通調整の対象一覧にも複数列を適用する。
- 記事全体でページ番号を通す。

## 暫定制約
- 最小縮小率70%、フッター余白24px以上を維持する。
- 文字切れ、重なり、調整項目の欠落・重複を禁止する。

## 実装順序
- [x] ① レイアウト仕様確定
- [x] ② 2列配置
- [x] ③ 3列配置
- [x] ④ 複数キャラクター配置
- [x] ⑤ 列数自動選択・混在
- [x] ⑥ 共通調整の最適化
- [ ] ⑦ 改ページ・はみ出し検証
- [ ] ⑧ 回帰テスト・画像枚数比較

既存の画像生成経路を維持し、試作を独立して検証してから統合する。

⑤の混在描画・収容判定は専用テストで合格。自動選択による混在と自動改ページの総合検証は⑦・⑧で実施する。

- 標準フォントは Noto Sans CJK JP（日本語ゴシック体）。
- ⑥: 記事1485・1552のユーザー確認済み。1552の検証成果物は43ページ、117カード、117セグメント、最小フッター余白24px、overflowなし。画像枚数削減と自動改ページの追加検証は後続工程で扱う。

## STEP6-⑧ 画像付きレイアウト追加仕様（2026-11-26）
- 通常はヘッダー左に指定スタイル画像、全スタイル共通は実装済み全スタイル画像を横並びにする。
- コンパクトなヘッダーに合わせ画像を縮小し、比率維持・切り抜きなし。最大64px、横幅36%、間隔4pxは暫定。
- 各調整文右側の強化・弱体化等の文字を非表示とし、PATCH NOTE全体ヘッダーに7種類の矢印凡例を置く。
- 共通バランス調整の対象カードはキャラクター名を上段、調整内容を下段に配置する。
- 1552画像付き試作の添付結果：10ページ、117カード、117セグメント、旧レイアウトへのフォールバック0。ユーザーが画像表示を確認済み。
- 追加仕様の実装結果は次回テストで確認する。
