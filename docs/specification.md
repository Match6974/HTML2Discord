# HTML2Discord 仕様
公式ヒロアカUR NEWSの調整記事を1920×1080 PNGへ変換し、Discordへ個別画像として投稿する。ZIPはテスト配布用。
- 原文にない数値を推測しない。調整意図に明記された数値は出典付きで補完可能。
- 取得・解析・描画・投稿を分離する。外部文字列はHTMLエスケープして描画する。
- 自動改ページ、ページ番号、最低縮小率0.70、フッター間隔24px以上を現行試作の基準とする。
- 複数列配置で画像枚数を抑え、可読性を維持する。列数・文字サイズは今後検証。
- 本番Worker mhaur-news-discord と既存テストWorkerは移行中変更しない。
- 解析・色仕様は parsing-rules.md / color-rules.md、進捗は roadmap.md を参照。
